# Course Management System

## About the Project
The Course Management System is a user-friendly desktop application developed using C# and Windows .NET Framework. It is designed to efficiently manage courses, students, instructors, and related records through a centralized system, simplifying administrative tasks while improving accuracy, organization, and productivity.

## Technologies Used
- C#
- Windows Forms
- .NET Framework
- Microsoft SQL Server
- Visual Studio

## Features
- Student Management
- Course Management
- Instructor Management
- Add, Update, Delete and View Records
- Search Functionality
- Database Integration
- User-Friendly Interface

## Project Purpose
The purpose of this project is to simplify course-related administrative tasks, reduce manual work, and provide an organized approach to managing academic information.
